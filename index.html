Central Processing Unit (CPU)

The "Brain" of the Computer

The CPU fetches instructions from memory, decodes them, and executes them using its internal arithmetic, logic, and control circuitry. It coordinates all hardware operations.

Key Sub-Components:

  • ALU: Executes arithmetic and logical operations.

Comprehensive Guide: System Architecture & Data Flow

Detailed breakdown addressing Question 2: Flow of data, instructions, and control signals.

1. Central Processing Unit (CPU)

The CPU is the primary engine of the computer system. It orchestrates all computational tasks through three major constituent units:

  • • Arithmetic Logic Unit (ALU): Performs mathematical calculations (+, -, *, /) and logical decisions (AND, OR, comparisons).
  • • Control Unit (CU): Acts as the system manager. It fetches instructions from memory, decodes them, and issues timing and control signals to hardware components.
  • • Register File: Ultra-fast storage locations including the Program Counter (PC), Instruction Register (IR), and Accumulator (AC).

2. Memory Unit (Primary Storage)

The primary memory (RAM/ROM) holds active programs and data currently in execution. Key characteristics include:

  • • Random Access Memory (RAM): Volatile memory where instructions and working data reside. Directly accessible by the CPU via the memory bus.
  • • Read-Only Memory (ROM): Non-volatile memory containing critical boot firmware (BIOS/UEFI).
  • • Addressability: Each memory cell has a unique binary address, enabling precise read/write operations.

3. Input / Output (I/O) Interfaces

I/O interfaces bridge the gap between the computer's high-speed internal bus and external peripheral devices:

  • • Input Peripherals: Keyboards, mice, scanners, and sensors translate physical user input into digital signals.
  • • Output Peripherals: Displays, printers, and actuators present processed data to the user or physical environment.
  • • Buffer & Controller: Matches speed discrepancies between fast CPU and slow mechanical or human interfaces.

The Flow of Data, Instructions, and Control Signals

How the CPU, Memory, and I/O interact during the classic Fetch-Decode-Execute cycle.

01

Instruction Fetch (IF)

The Control Unit places the address from the Program Counter (PC) onto the Address Bus. A memory read control signal is asserted. The Memory Unit returns the instruction over the Data Bus into the CPU's Instruction Register (IR).

Bus Used: Address Bus + Data Bus
02

Instruction Decode (ID)

The Control Unit analyzes the binary opcode residing in the Instruction Register. It determines what operation needs to be performed (e.g., ADD, LOAD, STORE) and generates the precise internal control signals to configure the ALU and data paths.

Signal Type: Control Signals
03

Execution (EX) & Writeback

The ALU executes the operation using operands from registers or memory. Results are written back to registers or stored back into memory via the Data Bus. The Program Counter (PC) increments to point to the next sequential instruction.

Bus Used: Data Bus + Control Bus
